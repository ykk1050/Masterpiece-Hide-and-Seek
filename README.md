# 명화 속 숨바꼭질 (Masterpiece Hide and Seek)

미술 시간에 쓰는 **2D 카멜레온 숨바꼭질 게임**입니다.
선생님이 명화를 골라 방을 만들면, 학생들은 흰색 캐릭터(사람·동물)로 들어와서
그림 위 원하는 자리에 숨고, **그 자리의 명화와 똑같이 캐릭터를 색칠**해 위장합니다.
시간이 끝나면 술래가 **확대할 수 없는 그림 전체 화면**을 보며 숨은 친구를 찾아냅니다.

> 현재 버전은 **프로토타입(v0.1)** 입니다.

## 게임 흐름

1. **방 만들기 (선생님)** – 명화 선택(기본 15점 또는 직접 업로드) → 설정 → 방 만들기
2. **입장 (학생)** – 방 번호 4자리 + 이름 + 캐릭터 모양(사람·고양이·강아지·토끼·새·물고기)
3. **숨기** – 선생님이 시작을 누르면 제한 시간 동안
   - 왼쪽 그림을 누르거나 끌어서 캐릭터 위치를 정하고
   - 오른쪽 확대 창에서 붓·채우기·스포이드·지우개로 한 칸씩 색칠합니다.
   - `👀 원래 그림 보기`를 누르고 있으면 캐릭터 아래의 원래 그림을 비교해 볼 수 있어요.
   - 다 그렸으면 `✅ 그리기 완료`를 누릅니다. **모두 완료하면 시간이 남아도 바로 찾기가 시작**돼요. (`다시 그리기`로 취소 가능)
4. **찾기**
   - 술래는 무작위 또는 선생님이 지정합니다.
   - 술래는 그림 전체를 **확대 없이** 보고 숨은 친구를 클릭합니다.
   - **찾으면** 그 술래가 계속 찾고, **놓치면(또는 시간 초과)** 아직 술래를 해 보지 않은 친구에게 차례가 넘어갑니다.
   - **태블릿(터치)**: 한 번 탭은 살펴보기, **두 번 탭하면** "이 위치에 친구가 숨어 있다고 생각하나요?" 확인 창이 떠서 실수로 선택하는 것을 막아요.
   - **돋보기 찬스**: 술래 3명이 연속으로 못 찾으면 다음 술래는 마우스 주변을 2.5배로 확대해 보는 돋보기를 쓸 수 있어요.
   - 술래를 해 볼 수 있는 친구가 더 없거나 모두 발견되면 끝납니다.
5. **결과** – 모든 캐릭터 공개, 끝까지 숨은 "위장의 달인"과 가장 많이 찾은 "매의 눈" 발표.
   학생마다 **그림 속 원래 색 vs 내가 칠한 색**을 나란히 보여 주고 색 일치도(%)를 보여 줍니다.

## 가장 쉬운 방법: 인터넷에 올려 두기 (한 번만 설정)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ykk1050/Masterpiece-Hide-and-Seek)

1. 위 버튼 클릭 → Render 가입(GitHub 계정으로 로그인) → **Apply / Deploy**
2. 몇 분 뒤 주소가 생깁니다. (현재 운영 주소: https://masterpiece-hide-and-seek.onrender.com)
3. 선생님은 `주소/teacher.html`, 학생은 `주소/play.html` 로 접속 — 설치·와이파이·방화벽 신경 쓸 필요 없음.

> 무료 요금제는 15분 동안 아무도 안 쓰면 잠들어서, 수업 시작 때 첫 접속이 30초~1분 걸릴 수 있어요. 수업 직전에 선생님 화면을 한 번 열어 두세요.

## 교사 PC에서 직접 실행하기 (인터넷 없이 쓸 때)

필요한 것: [Node.js](https://nodejs.org/) 18 이상

```bash
npm install
npm start
```

- 선생님: 교사 PC에서 `http://localhost:3000/teacher.html`
- 학생: 같은 와이파이에서 `http://<교사 PC IP>:3000/play.html`
  (서버를 켜면 터미널과 선생님 대기실 화면에 접속 주소가 표시됩니다)

> Windows에서 처음 실행할 때 방화벽 허용 창이 뜨면 **개인 네트워크 허용**을 눌러야 학생 기기에서 접속할 수 있어요.

### 명화 이미지

기본 명화는 모두 퍼블릭 도메인이며 [Wikimedia Commons](https://commons.wikimedia.org/)에서 가져옵니다.
교사 PC 서버가 처음 한 번 내려받아 `cache/` 폴더에 저장하고, 학생 기기는 교사 PC에서 그림을 받습니다.
인터넷이 안 되는 환경에서는 **직접 올리기**로 그림 파일을 업로드하면 됩니다.

## 선생님 설정

| 설정 | 설명 |
| --- | --- |
| 숨는 시간 | 자리 잡기 + 색칠 시간 (1~15분), 진행 중 `+1분`, `지금 찾기 시작` 가능 |
| 술래 한 번 시간 | 술래 차례마다 주어지는 시간, 찾을 때마다 다시 채워짐 |
| 술래 정하기 | 무작위 / 선생님이 지정 |
| 틀려도 되는 횟수 | 술래가 몇 번 놓치면 교대할지 (기본 1번) |
| 캐릭터 크기 | 작게 / 보통 / 크게 – 작을수록 찾기 어려움 |
| 스포이드 허용 | 끄면 그림에서 색을 뽑을 수 없어 직접 색을 섞어 맞춰야 함 (색채 학습용) |
| 대신 클릭하기 | 찾기 중 교사 화면(프로젝터)에서 술래 대신 클릭 |
| 캐릭터 미리보기 | 숨기 중 교사 화면에 학생 캐릭터 위치 표시 (프로젝터에 띄울 땐 끄기) |

## 폴더 구조

```
server.js            HTTP + Socket.IO 서버
src/game.js          방·단계·술래 차례·클릭 판정 로직
src/paintings.js     기본 명화 목록과 이미지 캐시
shared/shapes.js     캐릭터 모양 정의 (서버/브라우저 공용)
public/
  index.html         첫 화면
  teacher.html       선생님 화면
  play.html          학생 화면
  js/common.js       그림 불러오기·색 추출·그리기 도구
  js/views.js        술래 뽑기 연출, 클릭 표시, 결과 카드
  js/editor.js       색칠 도구
  js/teacher.js      선생님 화면 동작
  js/student.js      학생 화면 동작
```
